# Protein Studio — Мой Wellness v2

Обновлённая версия: визуальный стиль в направлении макета Protein Studio, расширенные 30 тем, выбор владельцем 10 тем на новый цикл, статистика без тестовых участников/звёзд/встреч, пустой чат и исправленный PWA.

Темы написаны заново по мотивам изученных материалов, а не копируются дословно.

Демо: owner@protein.studio / 1234 · curator@protein.studio / 1234 · client@protein.studio / 1234

Важно: это фронтенд-прототип; общая база, настоящая авторизация, межустройственный чат и push-уведомления требуют backend/БД.
